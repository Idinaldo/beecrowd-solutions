# Beecrowd Solutions
This is a simple repository just for me to keep my solutions of beecrowd problems.

## How to test solutions
It's simple!
1. identify the question code — generally, look at the commit message, it is always "solution: add problemName - problemCode".
2. search for it in beecrowd (judge.beecrowd.com)
3. get the solution code (I recommend copying the code)
4. paste it into the beecrowd interface
5. submit it!
